# Royal School, Ndola — website demo

An upgraded website concept for [Royal School](https://www.royalschoolndola.com/), a primary and secondary school on Buteko Avenue, Ndola, Zambia.

This is a **demo** by [Sban Technologies](https://github.com/soxman604-commits), built so the school can see online applications, a parent notice board, and a fees checkout on a phone. Enrolment messages open in WhatsApp. Fee payments on this site are simulated: no real money is charged, and the amounts shown are example fees only.

Live demo: https://soxman604-commits.github.io/royal-school-demo/
